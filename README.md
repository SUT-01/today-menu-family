# 今天吃什么

纯前端家庭菜单，内置 153 道菜谱。新增椒麻虾片（椒麻大虾），按用户提供的连续截图记录完整调料与 14 个步骤，原图保留作者信息。

所有字体使用系统字体，图片和 OCR 资源随站点提供，页面运行不依赖外部 CDN 或后台 API。

手机使用：GitHub Pages 开启后，用手机浏览器打开发布地址即可，也可把同一个链接发给家人。无需安装 ChatGPT，也不需要访问者登录 GitHub。

本地使用：完整下载并解压此目录，保持 index.html、images/、ocr/ 的相对位置，再用桌面浏览器打开 index.html。截图 OCR 建议在 HTTPS 网页中使用。

菜单修改和点单只保存在当前浏览器，不会自动同步给其他人；手机和电脑之间需要导出、导入备份。

截图原方未注明的用量保持为“适量/少许”，不是精确称量配方。其他已有菜谱保留各自的来源备注。
